## 简体中文

- 提供由 GitHub Actions 构建并使用固定发布证书签名的 Android APK（Android 8.0+）。
- 修复输入停止后偶尔迟迟不翻译的问题，触发等待缩短至约 0.45 秒。
- 浮窗分别显示发送中、等待服务端回复和完成状态；改善窄屏及软键盘下的布局。
- 支持 OpenAI、Claude、Qwen、Kimi、MiniMax、DeepSeek、Google AI 和自定义兼容服务。

下载 `ToneIME-0.3.2-android.apk` 安装。安装包已内置界面代码，无需 Metro；使用翻译功能需要自行配置 API Key。`SHA256SUMS` 用于校验下载，`SIGNING-CERTIFICATE.txt` 提供公开签名指纹。如果已安装旧的调试版，需先卸载调试版再安装正式版；卸载会清除本地设置和已保存的 API Key。

## 日本語

- GitHub Actions でビルドし、固定のリリース証明書で署名した Android APK を提供します（Android 8.0 以降）。
- 入力停止後に翻訳が始まらない場合がある問題を修正し、開始までの待機を約 0.45 秒に短縮しました。
- 送信中、サーバーの応答待ち、完了の状態を表示し、狭い画面とソフトキーボード使用時のレイアウトを改善しました。
- OpenAI、Claude、Qwen、Kimi、MiniMax、DeepSeek、Google AI、カスタム互換サービスに対応します。

`ToneIME-0.3.2-android.apk` をダウンロードしてインストールしてください。Metro は不要です。翻訳にはご自身の API キーを設定してください。`SHA256SUMS` はファイルの検証用、`SIGNING-CERTIFICATE.txt` は公開署名情報です。旧 debug 版から移行する場合は、先に debug 版をアンインストールしてください。ローカル設定と保存済み API キーは削除されます。

## English

- Android 8.0+ APK built by GitHub Actions and signed with a persistent release certificate.
- Fixed intermittent delays after typing stops and reduced the trigger delay to about 0.45 seconds.
- Added sending, waiting-for-response, and completion states; improved the overlay on narrow screens and around the keyboard.
- Supports OpenAI, Claude, Qwen, Kimi, MiniMax, DeepSeek, Google AI, and custom compatible services.

Install `ToneIME-0.3.2-android.apk`. The UI bundle is included, so Metro is not required. Configure your own API key to translate. Use `SHA256SUMS` to verify the download and `SIGNING-CERTIFICATE.txt` to inspect the public signing fingerprint. If an older debug build is installed, uninstall it before installing this release; uninstalling removes local settings and saved API keys.
