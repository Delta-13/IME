## 简体中文

- 新增跟随系统、浅色和深色外观，自动保存选择，并同步主界面、浮窗、状态栏和导航栏。
- 为正文、次要文字、占位符、菜单、错误提示和请求分段计时统一明暗配色；自动测试检查普通文字对比度至少 4.5:1、交互边界至少 3:1。这不代表完整的无障碍认证。
- 浮窗透明度仅影响外层背景，文字、按钮和内容底板保持不透明，避免底层应用影响可读性。
- 切换外观不会保存未完成的 API 表单、清空原文或重置正在进行的请求。

下载 `ToneIME-0.3.4-android.apk`（Android 8.0+，无需 Metro）。使用与 v0.3.3 相同的发布证书，可覆盖更新并保留设置。旧调试版证书不同，需先卸载；卸载会清除本地设置及保存的 API Key。翻译需要配置自己的 API Key。

## English

- Added system, light, and dark appearance modes. Your choice is saved and applied to the main screen, overlay, status bar, and navigation bar.
- Unified theme colors for body text, secondary text, placeholders, menus, errors, and request timings. Automated tests check normal text contrast of at least 4.5:1 and interactive boundaries of at least 3:1; this is not a complete accessibility certification.
- Overlay opacity now affects only the outer background. Text, buttons, and content backplates stay opaque for readability over other apps.
- Changing appearance does not save unfinished API settings, clear source text, or reset an active request.

Install `ToneIME-0.3.4-android.apk` (Android 8.0+, no Metro required). The same release certificate as v0.3.3 allows in-place updates that preserve settings. Older debug builds use a different certificate and must be uninstalled first; uninstalling removes local settings and saved API keys. Configure your own API key to translate.

Use `SHA256SUMS` to verify the download and `SIGNING-CERTIFICATE.txt` to inspect the public signing fingerprint. No API keys or signing secrets are bundled with this release.
