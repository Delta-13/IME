## 简体中文

- 浮窗新增准确的请求分段计时：排队、准备、DNS、连接、TLS、上传、等待响应、接收、解析及总耗时。
- 使用真实网络事件和单调时钟记录耗时，界面每 100 毫秒刷新；连接与 TLS 不重复统计，重试耗时累计，连接复用时标注跳过的阶段。
- 请求失败后保留最后阶段和耗时；修改输入时取消旧请求，避免过期回调覆盖新请求。
- 计时仅保存在内存，不记录或上传 API Key、请求地址、原文或译文。HTTPS 证书验证保持启用；HTTP 重定向作为错误处理，避免转发凭据。
- 新增 10 项单元与本地 HTTPS 集成测试，覆盖延迟响应、连接复用、取消、解析失败和证书校验。

总耗时从提交网络任务开始，不包含停止输入后的约 0.45 秒防抖等待。“上传”表示本地写出，不代表服务端确认；“等待响应”从正文写出到收到响应头，包含网络往返和服务端等待，并非纯模型计算时间。收到响应头后的正文等待计入“接收”。

下载 `ToneIME-0.3.3-android.apk` 安装（Android 8.0+，无需 Metro）。使用与 v0.3.2 相同的发布证书，可直接覆盖更新并保留设置。旧调试版使用不同证书，需要先卸载；卸载会清除本地设置和已保存的 API Key。使用自己的 API Key 进行翻译。`SHA256SUMS` 用于校验下载，`SIGNING-CERTIFICATE.txt` 提供公开签名指纹。

## 日本語

- フローティングウィンドウにリクエストの段階別計測を追加しました：キュー待ち、準備、DNS、接続、TLS、送信、応答待ち、受信、解析、合計時間。
- 実際のネットワークイベントと単調時計で記録し、表示は 100 ミリ秒ごとに更新します。接続と TLS は重複集計せず、再試行の時間は累積し、接続再利用で省略した段階を明示します。
- 失敗時は最後の段階と計測値を保持します。入力変更時は古いリクエストをキャンセルし、古いコールバックによる新しい結果の上書きを防ぎます。
- 計測情報はメモリ内のみで保持し、API キー、リクエスト URL、原文、訳文を記録・送信しません。HTTPS 証明書検証は有効のままです。認証情報の転送を防ぐため、HTTP リダイレクトはエラーとして扱います。
- 応答の遅延、接続再利用、キャンセル、解析失敗、証明書検証を確認する単体・ローカル HTTPS 結合テストを 10 件追加しました。

合計時間はネットワークタスクの投入時点から計測し、入力停止後の約 0.45 秒の待機は含みません。「送信」はローカルでの書き出しを示し、サーバーによる受領確認ではありません。「応答待ち」は本文の送信完了から応答ヘッダー受信までで、通信とサーバーの待ち時間を含むため、モデルの計算時間だけを表すものではありません。ヘッダー受信後の本文待ちは「受信」に含みます。

`ToneIME-0.3.3-android.apk` をインストールしてください（Android 8.0 以降、Metro 不要）。v0.3.2 と同じリリース証明書で署名するため、設定を保持して上書き更新できます。旧 debug 版は証明書が異なるため、先にアンインストールしてください。アンインストールするとローカル設定と保存済み API キーが削除されます。翻訳にはご自身の API キーを設定してください。`SHA256SUMS` はダウンロードの検証用、`SIGNING-CERTIFICATE.txt` は公開署名情報です。

## English

- Added accurate request timings to the overlay: queue, preparation, DNS, connection, TLS, upload, response wait, receive, parse, and total elapsed time.
- Measurements use real network events and a monotonic clock; the display refreshes every 100 ms. Connection and TLS time are counted separately, retries accumulate, and connection reuse marks skipped stages.
- Failed requests retain their final stage and measurements. Editing the input cancels the previous request so stale callbacks cannot replace newer results.
- Timing data stays in memory and does not record or transmit API keys, request URLs, source text, or translations. HTTPS certificate validation remains enabled. HTTP redirects are treated as errors to prevent forwarding credentials.
- Added 10 unit and local HTTPS integration tests covering delayed responses, connection reuse, cancellation, parse errors, and certificate validation.

Total elapsed time starts when the network task is submitted and excludes the approximately 0.45-second typing debounce. Upload measures local writes, not server acknowledgement. Response wait runs from writing the request body to receiving response headers and includes network latency and server waiting, not just model computation. Body delays after response headers arrive count as receive time.

Install `ToneIME-0.3.3-android.apk` (Android 8.0+, no Metro required). It uses the same release certificate as v0.3.2, allowing an in-place update that preserves settings. Older debug builds use a different certificate and must be uninstalled first; uninstalling removes local settings and saved API keys. Configure your own API key to translate. Use `SHA256SUMS` to verify the download and `SIGNING-CERTIFICATE.txt` to inspect the public signing fingerprint.
